Prenez les commandes

À vous de voir.

Tourner autour du modèle
Faites glisser avec la souris ou avec un doigt.
Rapprocher ou éloigner
Utilisez la molette, pincez avec deux doigts ou utilisez les boutons + et −.
Déplacer le point de vue
Faites glisser avec le bouton droit ou avec deux doigts.
Explorer au clavier
Placez le focus sur le modèle avec Tab, puis utilisez les flèches pour tourner. Les commandes de zoom sont accessibles avec Tab.

Les points de vue et le bouton de réinitialisation vous permettent de retrouver vos repères.

Réalité augmentée · WebXR

Une autre dimension.

La réalité augmentée n’est pas disponible dans ce navigateur. Ouvrez cette page en HTTPS sur un smartphone compatible, puis touchez « Réalité augmentée ».

Selon l’appareil, la visite utilise WebXR, Scene Viewer sur Android ou Quick Look sur iPhone et iPad. L’accès à la caméra peut être demandé par votre appareil.

La visualisation 3D reste accessible ici, sur ordinateur comme sur mobile.
