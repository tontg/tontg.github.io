Position

Manual position is fixed, not live GPS. Update it or confirm arrival as you move.

XR north alignment

Use a known north reference. After starting alignment, face that direction and hold still for 3 seconds. Calibration lasts for this XR session only.

Arrival feedback

Edit / import journey

Click the map to add a point; drag markers to move them. Edits are a draft until applied. Point field changes need Save point. Applying starts a new, paused journey.

Journey steps

    Choose one route, track segment, or waypoint list. Each point becomes a step; maximum 500 points. Dense tracks should be simplified first.
